# لعبة المهام بين الزوجين 🔥💋

تطبيق ويب تفاعلي للأزواج يعمل أونلاين وأوفلاين.

## المميزات
- واجهة زوج (حمراء) وواجهة زوجة (وردية رومانسية)
- 40 طلباً افتراضياً لكل طرف (قابلة للتعديل)
- القوائم سرية تماماً
- نظام أدوار متبادل (لا يمكن إرسال طلبين متتاليين)
- رمز غرفة مشترك لربط الجهازين
- يعمل محلياً بدون إنترنت للتجربة، ومع Firebase للأونلاين الحقيقي

## طريقة الاستخدام السريعة (بدون Firebase)

1. افتح ملف `index.html` في المتصفح (أو ارفعه على أي استضافة).
2. اختر "دخول كزوج" أو "دخول كالزوجة".
3. أدخل نفس رمز الغرفة في الجهازين (مثال: 12345).
4. اضغط "انضمام".
5. من يبدأ يضغط الزر الكبير لإرسال طلب عشوائي.

> ملاحظة: في الوضع المحلي (بدون Firebase) يعمل بشكل أفضل على نفس الجهاز للتجربة، أو باستخدام نفس المتصفح مع تبويبين.

## تفعيل الوضع الأونلاين الحقيقي (بين جهازين بعيدين)

1. اذهب إلى [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً جديداً.
2. من القائمة اليسرى اختر **Realtime Database** → أنشئ قاعدة بيانات في وضع الاختبار (Test mode).
3. من إعدادات المشروع (Project Settings) انسخ بيانات التكوين.
4. افتح ملف `app.js` واستبدل قيم `firebaseConfig` بالبيانات الخاصة بك.
5. ارفع الملفات على أي استضافة (Netlify, Vercel, GitHub Pages, أو حتى استضافة عادية).

بعدها يعمل التزامن الفوري بين أي جهازين يستخدمان نفس رمز الغرفة.

## تعديل القوائم
- اضغط زر "تعديل قائمتي" داخل اللعبة.
- يمكنك إضافة / تعديل / حذف أي طلب.
- التغييرات تُحفظ تلقائياً على جهازك (LocalStorage).

## الصور الإيحائية
حالياً تستخدم إيموجي. يمكنك لاحقاً استبدالها بروابط صور أنيمي/كارتون ساخنة بإضافة حقل `image` في كل طلب.

## الملفات
- `index.html` → الهيكل
- `styles.css` → التصميم (أحمر للزوج / وردي للزوجة)
- `app.js` → كل المنطق + القوائم الافتراضية
- `README.md` → هذا الملف
